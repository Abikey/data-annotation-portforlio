# Object Detection - Bounding Box Annotation

## Project Overview

This project demonstrates practical experience in image annotation using bounding boxes for object detection.

## Annotation Type

- Bounding Box Annotation
  
## Tool Used

  - CVAT
    
 
## Objective

To Accurately identify and localize objects within images by drawing bounding boxes around each target object and assigning the appropriate label.

## Annotation Process

1. Reviewed each image
2. Identified the target objects.
3. created bounding boxes around each object
4. Assigned the appropriate class label.
5. Reviewed the annotations for accuracy and consistency.

## Quality Assurance

Annotations were reviewed to ensure:
- objects were fully enclosed by the bounding box.
- Bounding boxes were positioned  accurately.
- Correct class labels were assigned.
- No relevant objects were missed.
- Unnecessary background areas were not included.
