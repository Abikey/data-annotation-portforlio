# Aerial/Geospatial Image Annotation - Building

## Project Overview

This project demonstrates practical experience annotating aerial imagery using polygon annotation.

## Annotation Type

- Polygon Annotation

 ## Tool Used

  - Label Studio

 ## Object Annotated

  - Building
 
 ## Annotation Process

  1. Reviewed the Aerial Image.
  2. Identified the building to be annotated.
  3. Placed polygon points along the visible boundary of the building.
  4. Carefully followed the building's shape and edges.
  5. Reviewed the annotation for accuracy and completeness.
 
 ## Quality Assurance

The Annotation was reviewed to ensure:
- Polygon points followed the building boundary accurately.
- The entire target building was included.
- Unnecessary surrounding areas were minimised.
- The Annotation was consistence with Project requirements.
